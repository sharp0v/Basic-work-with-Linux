# Основы работы в Linux: базовые команды для начинающих

## Основные понятия

**Директория** - аналог папки в Windows, содержит файлы и другие директории  
**Файл** - единица хранения информации в системе  
**Путь** - адрес расположения файла или директории в файловой системе  

## Основные команды

### Навигация
- `pwd` - показать текущую директорию
- `ls` - список файлов и папок
  - `ls -l` - подробный список
  - `ls -a` - показать скрытые файлы
- `cd [путь]` - перейти в директорию
  - `cd ..` - на уровень выше
  - `cd ~` - в домашнюю директорию

### Работа с файлами
- `touch имя_файла` - создать файл
- `cat имя_файла` - просмотреть содержимое файла
- `cp исходный_файл копия` - копировать файл
  - `cp -r папка копия_папки` - копировать папку
- `mv исходный новый` - переместить или переименовать
- `rm файл` - удалить файл
  - `rm -r папка` - удалить папку

### Работа с директориями
- `mkdir имя_папки` - создать папку
- `rmdir имя_папки` - удалить пустую папку

## Полезные советы

1. Используйте Tab для автодополнения команд и путей
2. Стрелки вверх/вниз - просмотр истории команд
3. `man команда` - справка по команде (например `man ls`)
4. `sudo` - выполнение команд с правами администратора
5. `clear` - очистить экран терминала
